* DELETE
- When we use delete , we want to delete data of a table .
- We delete specific rows 
- There is no changes in table's structure
- Yes , we use WHERE for conditions
- To delete the data of a table.

*TRUNCATE
- All rows of a table gonna be deleted
- Table and structure of the table remain safe 
- No use of WHERE
- To delete All the rows / data of the table.

* DROP
- Rows gonna be deleted
- Table gonna be deleted , this function deletes both Roe & Column
- No use of WHERE 
- To delete table or database.

SELECT department, count(*) AS employee_count, sum(salary) AS 
total_salary, AVG(salary) AS
average_salary, MIN(salary) AS 
minimum_salary, MAX(salary) AS
maximum_salary
FROM employees
GROUP BY department
HAVING employee_count >= 2
AND total_salary > 100000 
ORDER BY total_salary DESC ;
